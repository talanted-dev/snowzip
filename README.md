# ❄️ SnowZIP

**SnowZIP** — лёгкий архиватор для Windows с графическим интерфейсом и собственным форматом архивов `.snzip`.

Проект написан на **C и NASM** с использованием **zlib** для сжатия данных.

## ✨ Возможности

- 📦 Создание архивов `.snzip`
- 📂 Открытие существующих архивов
- 📤 Распаковка файлов через графический интерфейс
- 📋 Просмотр содержимого архива
- 🗑️ Удаление файлов из списка перед упаковкой
- 🧮 Проверка целостности данных с помощью CRC-32
- 🎨 Собственная иконка приложения

## 🛠️ Технологии

| Технология | Назначение |
|---|---|
| C | Основная логика и графический интерфейс |
| Win32 API | Нативный интерфейс Windows |
| NASM | Реализация CRC-32 на ассемблере |
| zlib | Сжатие и распаковка данных |
| MinGW-w64 GCC | Компиляция C-кода |
| GNU Make | Автоматизация сборки |

## 📋 Требования

- Windows 10 или новее
- MSYS2 с окружением **MinGW-w64 x86-64**
- GCC
- NASM
- GNU Make
- zlib и необходимые библиотеки Windows SDK, доступные в окружении MinGW-w64

## 🔨 Сборка из исходников

1. Установите MSYS2 и необходимые инструменты.
2. Убедитесь, что доступны команды `gcc`, `nasm`, `windres` и `make`.
3. Перейдите в каталог проекта:

   ```bash
   cd /path/to/SnowZIP
   ```

4. Соберите программу:

   ```bash
   make clean
   make
   ```

После успешной сборки появится `snowzip.exe`.
